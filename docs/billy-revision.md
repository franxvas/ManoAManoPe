# Aportes de Billy

Todos los aportes nuevos se reúnen en la rama existente `rama-billy`, conservando el historial anterior. El Pull Request de esta rama se revisa contra `main`.

El módulo incluye confirmaciones con código, portafolio de trabajos, reseñas de operaciones completadas e indicadores del perfil. Las migraciones se aplican en orden: `202610280001`, `202610280002`, `202610280003` y `202610280004`.

Las pruebas SQL se realizaron en PostgreSQL local con roles y superficies Auth y Storage simuladas. Todavía falta aplicar las migraciones a Supabase y comprobar la autenticación, las imágenes y Expo Go reales.

Los cambios locales anteriores de Inicio, SDK y catálogo permanecen en la carpeta original y no forman parte de este aporte. La guía de integración y demostración está en `docs/billy-integracion.md`.
